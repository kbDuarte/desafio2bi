## Como executar
1. Abra o projeto no Android Studio e aguarde a sincronização do Gradle.
2. Coloque o arquivo `google-services.json` em `app/` e habilite Email/Senha e Firestore no Firebase.
3. Inicie um emulador Android com acesso à internet e clique em **Run** para executar o aplicativo.
